Instalar o certificado do servidor

O painel roda no servidor do acampamento, fora da internet, com um certificado HTTPS próprio. Para o navegador confiar nele (e para poder instalar o painel como app), instale este certificado uma vez em cada celular ou computador que vai usar o painel.

Este servidor ainda não tem o certificado próprio. No servidor, rode ./deploy/install.sh (ou instale a versão nova pelo botão Atualizações).

Por segurança, este certificado só vale para o endereço deste servidor: ele não pode ser usado para se passar por outros sites (bancos, Google etc.). Na tela de instalação, confira se a impressão digital é a mesma mostrada aqui.

Android

  1. Toque em Baixar o certificado.
  2. Abra Configurações → Segurança → Mais configurações de segurança → Criptografia e credenciais → Instalar um certificado → Certificado de CA (o caminho muda um pouco de marca para marca; procure por "certificado" nas Configurações).
  3. Escolha o arquivo acessowifi-ca.crt em Downloads e confirme.

iPhone / iPad

  1. Abra esta página no Safari e toque em Baixar o certificado → Permitir.
  2. Abra Ajustes → Perfil Baixado (ou Ajustes → Geral → VPN e Gerenciamento de Dispositivo) e toque em Instalar.
  3. Depois, em Ajustes → Geral → Sobre → Ajustes de Confiança de Certificado, ative a chave do certificado "Acesso Wi-Fi". Sem este passo o iPhone não confia nele.

Windows

  1. Baixe e dê dois cliques no arquivo → Instalar Certificado.
  2. Escolha Máquina Local → Colocar todos os certificados no repositório a seguir → Autoridades de Certificação Raiz Confiáveis → Concluir.
  3. Feche e abra o navegador de novo.

Mac

  1. Baixe e dê dois cliques no arquivo: ele abre no Acesso às Chaves (chaveiro Sistema).
  2. Dê dois cliques no certificado "Acesso Wi-Fi" → Confiar → Ao usar este certificado: Sempre Confiar.

Instalar o painel como app

Com o certificado instalado, abra o painel pelo endereço do servidor:

  • Android / Chrome no computador: botão Instalar app no topo do painel (ou menu ⋮ → Instalar app).
  • iPhone / iPad: no Safari, botão Compartilhar → Adicionar à Tela de Início.

O app só funciona quando o aparelho alcança o servidor (rede do acampamento ou VPN). Ele não guarda dados no aparelho: usuários, senhas e conectados vêm sempre do servidor.
